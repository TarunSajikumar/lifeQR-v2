f_r = 1 / (2 * π * sqrt(L_ant * C_tune)) (3.1) • L_ant = 2.15 uH (Planar coil antenna) • C_tune = 50.0 pF (Silicon internal cap) • f_c = 13.56 MHz Carrier Frequency

Spatial Proximity Ambulance Radar

Haversine geodesic computation and real-time Socket.IO fleet synchronization

Haversine Great-Circle Distance
d = 2R * arcsin(sqrt( sin²(Δφ/2) + cos(φ1)*cos(φ2)*sin²(Δλ/2) )) (3.3) • R = 6,371 km (Earth mean radius) • φ1, φ2 = Victim and ambulance latitudes • Perimeter Threshold = 3.0 km

Security & Data Governance — Chapter 3.5 & 6.5

Database Models & Cryptographic Security

11 strictly typed Mongoose schemas with role-based access control (RBAC)

Database Collections & Separation
  • User & UserSecurity: Isolated credential storage.
  • PatientProfile: Blood group, allergies, medications, ICE contacts.
  • CrewProfile: GPS location, duty toggle, vehicle number.

  • Password Hashing: bcryptjs with salt rounds = 10.
  • Zero Plaintext Storage: Sensitive credentials never saved or exposed.
  • Token Security: Stateless JWT signed with HMAC-SHA256.
  • Role Middleware: Enforces access boundaries across all 5 roles.
  • Data Minimization: On-card memory stores only life-saving parameters.
