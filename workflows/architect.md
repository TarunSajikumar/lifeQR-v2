# Architect Agent Workflow — LifeQR

## Responsibilities
- Analyze incoming user requirements.
- Review current architecture in `brain/architecture.md` and `brain/master-memory.md`.
- Formulate execution specs and implementation plans.
- Identify potential breaking changes or security implications.

## Inputs & Outputs
- **Inputs**: User request, `brain/master-memory.md`, `brain/architecture.md`.
- **Outputs**: `implementation_plan.md` artifact.
