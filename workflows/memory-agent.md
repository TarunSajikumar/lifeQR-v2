# Memory Agent Workflow — LifeQR

## Responsibilities
- Update Project Brain memory files (`brain/`) after successful task completion or architectural decisions.
- Maintain `brain/master-memory.md` compressed under 5,000 words.
- Log new mistakes and their verified fixes into `brain/mistakes.md`.
- Update `brain/feature-map.md` and `brain/dependency-graph.md` when new modules are added.

## Inputs & Outputs
- **Inputs**: Completed task outputs, bug fix logs, architectural decisions.
- **Outputs**: Updated `brain/*.md` files and `AGENTS.md`.
